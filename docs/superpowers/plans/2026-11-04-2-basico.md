# 2° básico — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sumar 2° básico a VULPO como séptimo curso: currículum, banco aprobado, fork jugable, voz en R2 y arte.

**Architecture:** El camino de 4°, 5° y 6°: el contenido (`contenido/*-2basico/`) se escribe y se audita primero; el fork `2do/index.html` se clona de `4to/` cuando el reparto y el banco están revisados; la voz se genera después de la aprobación y va solo a R2. Spec: `docs/superpowers/specs/2026-11-04-2-basico-design.md`.

**Tech Stack:** JSON de contenido, Python (scripts de auditoría, voz y R2), HTML/JS del fork, `scripts/cdp.mjs` para verificar.
